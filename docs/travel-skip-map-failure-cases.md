# Skip map failure cases

- Tab from the selected region enters hundreds of map controls instead of offering Skip map first.
- Activating Skip map leaves focus inside the map, or the next Tab misses the visited journey links.
- Switching regions, an empty visited list, or the admin editor breaks the skip destination.
- Skipping changes selections or prevents existing map keyboard interactions.
- The focused link is clipped or causes horizontal overflow at 390 px.
- The link causes layout shifts, extra downloads, or runtime errors.
